# Quran Content

Downloadable data for the Quran app. See the [content catalog](catalog.json) for each asset's source, edition, exact download size, and SHA-256 checksum.

- [Quran content v1](https://github.com/Fexes/Quran-Content/releases/tag/content-v1) includes 77 QuranEnc translation editions, Al-Muyassar Tafsir, six Azkar languages, and 114 surah covers.
- [Smart Search v2](https://github.com/Fexes/Quran-Content/releases/tag/v2) is available as a single ZIP.

QuranEnc editions are the upstream SQLite archives, republished under [QuranEnc's terms](https://quranenc.com/en/home/api/). The Azkar archive includes its Apache 2.0 license and source notice. Each asset retains its own terms and attribution.

Recitation and spoken translation recordings are provided by their respective audio providers.
