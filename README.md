# Quran Content

Public downloads for the Quran app. Use the [content catalog](catalog.json) to find a specific edition, language, or surah.

## Downloads

| Content | Coverage | Download size |
| --- | --- | ---: |
| Quran translations | 77 QuranEnc editions across 57 languages | 50.4 MB total |
| Tafsir | Arabic Al-Muyassar | 0.82 MB |
| Azkar | Arabic, English, Persian, Russian, Sorani Kurdish, and Badini Kurdish | 0.28 MB |
| Surah covers | 114 JPEG images | 6.2 MB total |
| Smart Search v2 | Optional offline search pack in one ZIP | 126.7 MB |

Browse the [content release](https://github.com/Fexes/Quran-Content/releases/tag/content-v1) or [download Smart Search v2](https://github.com/Fexes/Quran-Content/releases/download/v2/quran-smart-search-v2.zip). Smart Search uses about 178 MB after installation. The catalog lists exact sizes in bytes.

Recitations and spoken translations are served by their respective audio providers.

## Catalog

The [JSON catalog](https://raw.githubusercontent.com/Fexes/Quran-Content/main/catalog.json) lists each pack's ID, type, version, download URL, size in bytes, and SHA-256 checksum. It also includes language and source information where available.
